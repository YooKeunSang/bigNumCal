# PRD: 한글 큰숫자(무극) 계산기 웹 앱

## 1. 개요

### 1.1 제품 비전
한글 숫자 단위(일~무극, 10⁰~10⁷²)를 지원하는 웹 기반 계산기 앱.
큰 숫자의 계산 결과를 한글로 변환하여 직관적으로 이해할 수 있도록 한다.

### 1.2 목표 사용자
- 한글 큰숫자 단위에 관심이 있는 일반 사용자
- 교육 목적으로 큰 숫자 단위를 학습하려는 학생
- 정밀한 큰 숫자 계산이 필요한 사용자

### 1.3 핵심 가치
- **정확성**: BigInt 기반으로 10⁷²(무극)까지 정밀 손실 없는 계산
- **직관성**: 숫자를 한글 단위로 변환하여 읽기 쉽게 표시
- **접근성**: 브라우저만 있으면 설치 없이 즉시 사용 가능

## 2. 기능 요구사항

### 2.1 계산기 모드 (3가지)

| 모드 | 설명 | 핵심 기능 |
|------|------|-----------|
| **한글 큰숫자** | 기본 모드 | 사칙연산 + 한글 변환 표시 |
| **표준** | 일반 계산기 | 사칙연산 + 부호 변경 |
| **공학용** | 과학 계산기 | 삼각함수, 로그, 거듭제곱, 상수 |

### 2.2 한글 큰숫자 모드 (핵심 기능)

#### 2.2.1 지원 단위
```
일(10⁰) → 십(10¹) → 백(10²) → 천(10³) → 만(10⁴) → 억(10⁸) → 조(10¹²) → 경(10¹⁶)
→ 해(10²⁰) → 자(10²⁴) → 양(10²⁸) → 구(10³²) → 간(10³⁶) → 정(10⁴⁰) → 재(10⁴⁴) → 극(10⁴⁸)
→ 항하사(10⁵²) → 아승기(10⁵⁶) → 나유타(10⁶⁰) → 불가사의(10⁶⁴) → 무량대수(10⁶⁸) → 무극(10⁷²)
```

#### 2.2.2 한글 변환 규칙
- 숫자 입력 시 실시간으로 한글 변환 결과를 하단에 표시
- 모든 단위를 조합하여 정확하게 표시 (생략 없음)
- 예시: `1,234,567,890,000,000,000` → `십이경 삼천사백오십육조 칠천팔백구십억`
- 음수: `마이너스` 접두사
- 소수: `점` 구분자 + 각 자릿수 한글 표기

#### 2.2.3 계산 엔진 요구사항
- BigInt 기반으로 정수 연산 시 정밀도 손실 없음
- 지원 연산: 덧셈(+), 뺄셈(-), 곱셈(×), 나눗셈(÷)
- 소수점 연산은 별도 로직으로 처리 (스케일링 방식)
- `eval()` 사용 금지 → 자체 수식 파서 구현

### 2.3 표준 계산기 모드
- 사칙연산 (+, -, ×, ÷)
- 소수점 계산
- 부호 변경 (+/-)
- AC(전체 지우기), CE(현재 입력 지우기), ⌫(백스페이스)

### 2.4 공학용 계산기 모드
- 삼각함수: sin, cos, tan
- 로그 함수: log(밑 10), ln(자연로그)
- 제곱근(√), 거듭제곱(x^y)
- 수학 상수: π, e
- 괄호 연산: (, )
- 괄호 자동 닫기 지원

### 2.5 공통 기능
- 키보드 입력 지원 (0-9, +, -, *, /, Enter, Escape, Backspace)
- 결과값 클립보드 복사 (숫자 / 한글 모두)
- 천 단위 콤마 포맷팅
- 사용자 배경화면 업로드/제거 (localStorage 저장)

## 3. 비기능 요구사항

### 3.1 성능
- 최대 76자리 숫자(무극 범위) 계산 시 100ms 이내 응답
- 한글 변환 실시간 표시 (입력 지연 없음)

### 3.2 보안
- eval() 미사용 → 코드 인젝션 방지
- 사용자 입력 검증 (숫자, 연산자, 함수만 허용)

### 3.3 호환성
- Chrome, Edge, Firefox, Safari 최신 버전 지원
- 반응형 디자인: 모바일(480px), 태블릿(768px), 데스크톱

### 3.4 접근성
- 키보드 네비게이션 완전 지원
- 한글 폰트 최적화

## 5. 사용자 시나리오

### 시나리오 1: 큰 숫자 한글 변환
1. 사용자가 `한글 큰숫자` 모드 선택
2. `999999999999999999` 입력
3. 디스플레이에 `999,999,999,999,999,999` 표시
4. 한글 영역에 `구백구십구경 구천구백구십구조 구천구백구십구억 구천구백구십구만 구천구백구십구` 표시

### 시나리오 2: 큰 숫자 곱셈
1. `1000000000000` 입력 → `×` → `1000000000000` 입력 → `=`
2. 결과: `1,000,000,000,000,000,000,000,000` (10²⁴)
3. 한글: `일자`

### 시나리오 3: 공학용 계산
1. `공학용` 모드 전환
2. `sin(` → `30` → `)` → `=`
3. 결과: `-0.9880316241`
