# 한글 큰숫자(무극) 계산기 웹

한글 큰숫자 표기법(무극까지)을 지원하는 웹 기반 계산기입니다.

## 주요 기능

### 1. 한글 큰숫자 계산기
- 숫자를 한글로 자동 변환 표시
- 무극(10⁷²)까지의 큰 숫자 단위 지원
- 지원하는 단위:
  - 기본: 일, 십, 백, 천, 만, 억, 조, 경
  - 큰 단위: 해, 자, 양, 구, 간, 정, 재, 극
  - 초대형 단위: 항하사, 아승기, 나유타, 불가사의, 무량대수, **무극**

### 2. 표준 계산기
- 사칙연산 (+, -, ×, ÷)
- 소수점 계산
- 부호 변경 (+/-)
- 연속 계산 지원

### 3. 공학용 계산기
- 삼각함수 (sin, cos, tan)
- 로그 함수 (log, ln)
- 제곱근 (√)
- 거듭제곱 (x^y)
- 수학 상수 (π, e)
- 괄호 연산

### 4. 배경화면 지원
- 사용자 정의 배경 이미지 업로드
- 로컬 스토리지에 배경 저장
- 배경 제거 기능

## 사용 방법

### 계산기 모드 전환
상단의 버튼을 클릭하여 모드를 전환할 수 있습니다:
- **한글 큰숫자**: 계산 결과를 한글로 표시
- **표준**: 기본 계산기
- **공학용**: 과학 계산 기능 포함

### 키보드 단축키
- `0-9`: 숫자 입력
- `+, -, *, /`: 연산자 입력
- `Enter`: 계산 실행
- `Escape`: 전체 지우기 (AC)
- `Backspace`: 한 글자 지우기

### 배경화면 설정
1. "배경화면 변경" 버튼 클릭
2. 원하는 이미지 파일 선택
3. "배경 제거" 버튼으로 기본 배경으로 복원

## 실행 방법

웹 브라우저에서 `index.html` 파일을 열면 바로 사용할 수 있습니다.

```bash
# 로컬 서버로 실행 (선택사항)
python -m http.server 8000
# 또는
npx serve
```

그 후 브라우저에서 `http://localhost:8000` 접속
